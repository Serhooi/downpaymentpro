# Публикация сайта на собственный домен

Цель: сайт открывается по адресу `downpaymentpro.ca` (и `www.downpaymentpro.ca`).

Важно: домен нельзя подключить, пока проект не опубликован. Публикация сначала создаёт адрес вида `имя.lovable.app`, и только после этого появляется возможность привязать свой домен. Поэтому порядок такой:

## Шаг 1 — Публикация
Публикую проект на Lovable-URL. Перед этим прогоняю проверку безопасности бэкенда (база, доступы к таблицам bookings и leads), чтобы не выкатывать критические находки.

## Шаг 2 — Подключение домена (делаешь ты, в настройках проекта)
1. Project Settings → Project → Domains → **Connect Domain**
2. Ввести `downpaymentpro.ca`, затем отдельной записью добавить `www.downpaymentpro.ca`
3. Выбрать Primary (обычно домен без www, www будет редиректить)
4. У регистратора добавить записи (в диалоге Lovable часто предлагает автонастройку):
   - A `@` → `185.158.133.1`
   - A `www` → `185.158.133.1`
   - TXT `_lovable` → значение из диалога
5. Если домен на Cloudflare — раскрыть **Advanced** и включить «Domain uses Cloudflare or a similar proxy» (проверка пойдёт через CNAME)
6. Дождаться распространения DNS (обычно минуты, максимум до 72 часов). SSL-сертификат Lovable выпустит сам.

Статус домена в настройках пройдёт путь: Verifying → Setting up → Active.

## Что нужно от тебя
- Подтвердить имя домена (исхожу из `downpaymentpro.ca`)
- Доступ к DNS у регистратора (или купить домен прямо в Lovable — тогда DNS редактируется внутри Lovable)

## Отдельно: почта
Верификация домена для отправки писем (`info@downpaymentpro.ca`) — это отдельный процесс от домена сайта. Пока она не пройдена, заявки и лиды надёжно сохраняются в базе, но письма не уходят. Могу заняться этим следующим шагом.
